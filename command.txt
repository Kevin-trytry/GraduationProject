════════════════════════════════════════════════════════════
  部署注意事項
════════════════════════════════════════════════════════════
  韌體關鍵設定（common_config.h）：
    FRAME_CHECK_DEBUG = 0              ← 必須為 0，否則黑畫面
    YOLOV8_OBJECT_DETECTION_FLASH_ADDR = 0x3AB7B000
    模型輸入解析度: 192 x 192
    UART 鮑率: 921600

  xmodem 模型燒錄位址對照表：
    Flash 完整位址 0x3AB7B000 → xmodem 燒錄參數 0xB7B000

  Python 端（grove_vision_capture.py）：
    支援動態切換傳輸模式（UART/SPI/UART+SPI）
    UART 模式下，INVOKE 訊息同時包含 boxes + JPEG 影像

  常見問題：
    1. 畫面全黑       → 確認 FRAME_CHECK_DEBUG = 0，重新 make + 燒錄
    2. 收不到資料     → 改用 --raw-debug 查看韌體原始輸出
    3. 框座標偏移     → 加上 --cam-width 640 --cam-height 480
    4. 燒錄失敗       → 確認 COM3 未被其他程式佔用，重試按鈕步驟
    5. 推論結果異常   → 確認模型燒錄位址與 common_config.h FLASH_ADDR 一致
