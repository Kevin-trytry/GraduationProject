## 五、模型參數調整建議

### 1. 調高 Score Threshold（信心度閾值）

目前閾值過低（15% 的偵測都被保留），導致大量低信心雜訊。

```c
// 建議調整範圍：
#define SCORE_THRESHOLD   0.35f   // 目前可能是 0.15 或更低
// 短期測試可以先試 0.35，觀察噪音是否減少
```

**預期效果**：過濾掉 25–50% 的低信心誤報，雖然總偵測數減少，但精確率會提升。

### 2. 加入 BBox 大小過濾

```cpp
// 在後處理階段過濾掉覆蓋整個畫面的框
// 過濾條件：面積 > 畫面的 85%
float frame_area = 320.0f * 240.0f;
float box_area   = box.w * box.h;
if (box_area / frame_area > 0.85f) continue;  // 跳過全畫面框
```

### 3. 多幀投票平滑（時序後處理）

在 Python 端（`grove_vision_capture.py`）加入投票機制：

```python
from collections import deque, Counter

# 在初始化時：
vote_window = deque(maxlen=5)  # 最近5幀的結果

# 在每幀偵測後：
vote_window.append(current_gesture)
if len(vote_window) == 5:
    stable_gesture = Counter(vote_window).most_common(1)[0]
    if stable_gesture[1] >= 3:  # 5幀中至少3幀一致才輸出
        output_gesture(stable_gesture[0])
```

**預期效果**：消除單幀噪音，cls2 的虛假偵測會被抑制。

### 4. 過濾不需要的類別

```python
# 在輸出前過濾掉不可靠或本應用不使用的類別
IGNORE_CLASSES = {10}  # 若不使用手掌側面(B)，加入過濾
# 可視應用需求調整，例如若不使用四指(9)也可加入
if det['cls_id'] in IGNORE_CLASSES:
    continue
```

### 5. 訓練資料建議（長期）

- 重新平衡各類別樣本數量（目前 cls2 嚴重過多）
- cls4（四指）、cls5（全開手掌）需要補充更多訓練樣本
- cls7（L形）和 cls6（Shaka）需要更多樣本區分兩者的差異（兩者都是兩指張開）
- cls8（三指）和 cls9（四指）外觀相差一根無名指，是**高混淆對**，需要針對性補充樣本
- 在當前測試環境（光線、距離）下補採訓練圖像，提升域適應

## 八、待實作功能（Future Work）

### 📌 多幀投票（Multi-frame Voting）

> [!NOTE]
> 待實作層、後續課題中補上。

**概念**：取最近 N 幀的偵測結果，用大多數投票決定穩定輸出，而非直接輸出每幀結果。

**效果**：
- 消除單幀噪音誤判
- 防止手勢切換過程中的輸出跳動
- 延遲約 5 幀 (~200ms)，實際應用不明顯

**計畫實作位置**：`grove_vision_capture.py` 的主迴圈偵測結果處理段

```python
from collections import deque, Counter

# 初始化：
vote_window = deque(maxlen=5)  # 最近 5 幀的結果

# 在每幀偵測後：
vote_window.append(current_cls_id)
if len(vote_window) == 5:
    top, count = Counter(vote_window).most_common(1)[0]
    if count >= 3:        # 5 幀中至少 3 幀一致
        output(top)       # 才輸出穩定手勢
    # 否則覆式广示不輸出（避免誊號跳動）
```
