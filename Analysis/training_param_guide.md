## 一、最關鍵修改：`IMAGE_SIZE`

> ⚠️ **這是最重要的一項，務必確認。**

```python
IMAGE_SIZE = 96    # 鏡頭解析度 96×96
                   # 原本若設 640，訓練時圖片比例與板子看到的完全不同
                   # 模型學到的特徵在板子上的 96×96 畫面中認不出來
                   # → 導致信心度普遍偏低、大多數手勢無法通過 threshold
```

**原因說明：**

| 情況 | 訓練 IMAGE_SIZE | 板子推論解析度 | 結果 |
|------|----------------|--------------|------|
| ❌ 現況 | 640 | 96×96 | 特徵不 match，信心度低 |
| ✅ 修正後 | **96** | 96×96 | 特徵一致，信心度提升 |

EPOCHS   = 150   # 原 100，樣本量約 200-300/class，多訓幾輪更穩定

## 三、Augmentation（應對相機色彩差異）

訓練資料用一般相機/手機拍攝，但板子上是 OV5647 鏡頭。
兩者色彩特性、亮度、對比度不同，需用 augmentation 補償。

```python
AUGMENT_CFG = dict(
    # ── 色彩調整（補償 OV5647 vs 一般相機的色彩差異）────────────
    hsv_h   = 0.03,   # 色調偏移（原 0.015，加大）
    hsv_s   = 0.7,    # 飽和度偏移（原 0.5，加大）
    hsv_v   = 0.5,    # 亮度偏移（原 0.4，加大）← 最重要，補償光線差異

    # ── 幾何調整 ─────────────────────────────────────────────────
    flipud  = 0.0,    # 上下鏡像：保持關閉（手不會倒著出現）
    fliplr  = 0.5,    # 左右鏡像：保留
    degrees = 10.0,   # ★ 新增：旋轉 ±10°，補償手腕角度變化
    scale   = 0.4,    # ★ 新增：縮放 ±40%，補償不同拍攝距離 vs 鏡頭距離差異

    # ── 合成增強 ─────────────────────────────────────────────────
    mosaic  = 1.0,    # Mosaic：保留（對中小型資料集有幫助）
    mixup   = 0.15,   # MixUp（原 0.1，略提高）
)
```

## 四、混淆手勢的對比樣本建議

以下幾組手勢在視覺上相近，訓練時容易互相干擾：

| 容易混淆的手勢 | 差異 | 建議 |
|--------------|------|------|
| cls8（三指：拇+食+中） vs cls9（四指：拇+食+中+無名） | 差一根無名指 | 補充清楚展開/收起無名指的對比樣本 |
| cls4（四根手指，無拇指） vs cls5（全開五指） vs cls9 | 拇指是否張開 | 確認標注時拇指角度清楚可見 |
| cls6（Shaka：拇+小指） vs cls7（L形：拇+食指） | 都是兩指張開 | 確認小指 vs 食指的角度差異在訓練圖中明顯 |

## 五、完整參數對照表

| 參數 | **建議值** | 原本值 | 原因 |
|------|-----------|--------|------|
| `IMAGE_SIZE` | **96** | 640 | 與鏡頭解析度一致 ← **最優先** |
| `EPOCHS` | 150 | 100 | 多訓練幾輪 |
| `PATIENCE` | 20 | 15 | 避免過早停止 |
| `hsv_v` | 0.5 | 0.4 | 補償亮度差異 |
| `hsv_s` | 0.7 | 0.5 | 補償飽和度差異 |
| `degrees` | 10.0 | 無 | 手腕角度補償 |
| `scale` | 0.4 | 無 | 距離差異補償 |
| `mixup` | 0.15 | 0.1 | 略提高 |

## 六、訓練後驗收標準

訓練完成後，確認以下指標再進行量化部署：

| 指標 | 門檻 | 說明 |
|------|------|------|
| `mAP@0.5`（測試集） | **> 0.75** | 低於此值不建議部署 |
| `mAP@0.5`（測試集） | < 0.60 | 資料或參數有問題，需重查 |
